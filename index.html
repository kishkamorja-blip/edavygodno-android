Подключение источников цен

Приложение подготовлено для загрузки каталогов в собственный интерфейс. Автоматический запрос цен к магазинам пока не включён: для него нужны разрешённый API или официальная выгрузка сети.

Не выдаём оценки за цены магазинов. Каждая позиция помечается источником: пользовательская цена, импортированный файл или демонстрационная оценка.
CSV: name,store,category,price,unit,observed_at,city. JSON: массив объектов с такими полями.
